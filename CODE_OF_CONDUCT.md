# Code de conduite

yawrdp adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En résumé, nous nous engageons à faire de la participation à ce projet une expérience sans harcèlement pour
tout le monde, quels que soient l'âge, le handicap, l'origine, l'identité ou l'expression de genre,
l'orientation sexuelle, le niveau d'expérience, la religion ou l'apparence.

**Attendu** : bienveillance, respect des avis différents, critiques constructives, reconnaissance de ses
erreurs.

**Inacceptable** : propos ou images à caractère sexuel, insultes, attaques personnelles, harcèlement
public ou privé, publication d'informations privées d'autrui sans son accord.

## Signalement

Signale tout comportement inacceptable aux mainteneurs, en privé, via le signalement privé de GitHub (voir
[SECURITY.md](SECURITY.md)) ou par message direct. Chaque signalement est traité rapidement, en toute
confidentialité. Les sanctions vont de l'avertissement à l'exclusion définitive, selon les lignes
directrices du Contributor Covenant.
