Préparer un PC Windows

Ça règle tout ce qu'il faut pour Portique sur Windows 10/11 Pro, sans rien installer. Lance l'un des deux outils en administrateur (clic droit). Tu peux le relancer sans risque.

Option A : fichiers .reg + .cmd
  • Télécharge les trois fichiers dans le même dossier : portique.reg, portique.cmd, annuler.reg.
  • Clic droit sur portique.cmd puis « Exécuter en tant qu'administrateur » : il importe le .reg et fait le reste.
Option B : un seul script PowerShell
  • Télécharge portique.ps1, puis dans PowerShell administrateur : powershell -ExecutionPolicy Bypass -File .\portique.ps1

Ce que ça change

  • Bureau à distance activé, authentification NLA obligatoire.
  • Graphiques : H.264 AVC 4:4:4, encodage matériel et GPU pour toutes les sessions, 60 images/s, qualité d'image haute.
  • Presse-papier, lecteurs, son et micro autorisés ; plus de déconnexion automatique.
  • Pare-feu : règles « Bureau à distance » activées.
  • Empreinte du certificat RDP affichée à la fin : à la première connexion, Portique montre une empreinte à l'admin, elle doit être identique avant de l'approuver.
  • Réveil à distance : carte réseau autorisée à réveiller le PC, démarrage rapide désactivé, adresse MAC affichée (à recopier dans Portique). Active aussi Wake-on-LAN dans le BIOS/UEFI.

Annuler

Option A : importe annuler.reg puis lance portique.cmd annuler (ou seulement la seconde commande, elle importe le .reg). Option B : .\portique.ps1 -Annuler.

Un redémarrage peut être nécessaire pour que les réglages graphiques s'appliquent.
