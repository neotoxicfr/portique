Préparer un PC Windows

Règle Windows 10/11 Pro pour Portique, sans rien installer. Lance l'un des deux outils en administrateur ; le relancer est sans risque.

Option A : fichiers .reg et .cmd

1
Télécharge les trois fichiers dans le même dossier.
portique.reg portique.cmd annuler.reg
2
Clic droit sur portique.cmd, puis « Exécuter en tant qu'administrateur ». Il importe le .reg et fait le reste.

Option B : un seul script PowerShell

1
Télécharge le script.
portique.ps1
2
Dans PowerShell administrateur, depuis son dossier : 
powershell -ExecutionPolicy Bypass -File .\portique.ps1

Ce que ça change

Bureau à distanceActivé, authentification NLA obligatoire.
GraphiquesH.264 AVC 4:4:4, encodage matériel et GPU pour toutes les sessions, 60 images/s, qualité d'image haute.
RedirectionsPresse-papier, lecteurs, son et micro autorisés ; plus de déconnexion automatique.
Pare-feuRègles « Bureau à distance » activées.
CertificatSon empreinte s'affiche à la fin. À la première connexion, Portique montre une empreinte à l'admin : elle doit être identique avant de l'approuver.
Réveil à distanceCarte réseau autorisée à réveiller le PC, démarrage rapide désactivé, adresse MAC affichée (à recopier dans Portique). Active aussi Wake-on-LAN dans le BIOS/UEFI.

Annuler

Option A : lance, en administrateur (il importe annuler.reg) : 
portique.cmd annuler
Option B : dans PowerShell administrateur : 
powershell -ExecutionPolicy Bypass -File .\portique.ps1 -Annuler

Un redémarrage peut être nécessaire pour que les réglages graphiques s'appliquent.
